# Severity Scoring

Use CVSS-style scoring for each finding:

| Severity | Score | SLA |
|----------|-------|-----|
| Critical | 9.0–10.0 | Fix immediately |
| High | 7.0–8.9 | Fix within 24–48 hours |
| Medium | 4.0–6.9 | Fix within one sprint |
| Low | 1.0–3.9 | Fix in next release |
| Info | 0.0 | Best practice improvement |

Factors to consider: exploitability, impact (confidentiality/integrity/availability), authentication required, user interaction required.
